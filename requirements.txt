# Pip packages for the `scenegen` env — the one that runs main.py and every
# stage module.
#
#     conda create -n scenegen python=3.10
#     conda activate scenegen
#     pip install -r requirements.txt
#
# Versions are the ones this release was developed and tested against. They are
# pinned with `>=` so a newer patch release is fine; loosen or tighten to taste.
#
# NOT covered here:
#   - torch/torchvision CUDA builds — install the wheel matching your driver
#     from https://pytorch.org before the rest of this file.
#   - the `vllm-env`, `eagle-embodied`, `lang-sam` and `hunyuan3d` envs, which
#     have their own dependency sets. `vllm-env` — which runs everything in
#     Qwen/ (fastapi, uvicorn, pydantic, diffusers, certifi) — has an exported
#     spec at environment_yml/vllm-env.yml; the other three do not. See
#     MODELS_AND_PATHS.md.
#   - the vendored clones' own requirements: vggt/requirements.txt and
#     Grounded-Segment-Anything's setup.
#   - Blender, which is an external binary (`BLENDER_BIN`).
